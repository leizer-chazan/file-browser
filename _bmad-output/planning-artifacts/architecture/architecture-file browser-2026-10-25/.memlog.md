- (constraint) Inherited from PRD/AGENTS: read-only, local-only, no persistence, no new deps, desktop Chrome only, styling via tokens.css only, src/lib framework-free.
- (decision) Scan source = disk re-read via retained FileSystemDirectoryHandle, NOT the File[] already in memory. Why: v1 collectDirectoryFiles throws on any unreadable entry so in-memory set can never contain skipped items (FR-5 untestable), cannot observe deletions mid-scan, and a re-open would re-aggregate a stale load-time snapshot (FR-7 'new scan' becomes cosmetic); in-memory aggregation of 10k is near-instant so FR-2 counter is meaningless. Disk read gives real per-file getFile() failures, real progress, true snapshot-at-scan-time per PRD glossary.
- (decision) Root FileSystemDirectoryHandle kept in in-memory React state only (allowed by no-persistence rule). Selected folder resolved by walking getDirectoryHandle over path segments from root.
- (decision) webkitdirectory fallback path has no handle -> Insights button unavailable when no root handle. Desktop Chrome always has showDirectoryPicker so this is unreachable in the supported platform.
- (decision) Scan engine lives in src/lib/folderInsights.ts, plain TS over a structural handle interface (moved out of App.tsx), testable with fake handles. Aggregation (byType, top10) are pure sync functions over {path,size} records, separate from traversal.
- (decision) Cancellation: AbortSignal passed into scan + existing requestId-ref pattern in App guarding every setState. Both required.
- (decision) Skips: getFile() reject -> skipped file (counted as processed). values()/getDirectoryHandle reject -> skipped folder, contents excluded, folder not counted as file.
- (decision) FR-11: guard cycles by checking isSameEntry against ancestor chain before descending; Chromium symlink enumeration behaviour unverified on web.
- (decision) Insights file type is a new function (getExtensionLabel) per PRD glossary+FR-6; v1 getFileType (MIME/uppercase) untouched. Sizes formatted with existing formatFileSize only.
- (decision) Ordering: byType size desc then label A-Z; top10 size desc then path case-insensitive then case-sensitive tiebreak (deterministic, no localeCompare locale variance) - use explicit comparator.
- (decision) Progress: scan reports count via onProgress callback; App throttles state updates; scan yields to the event loop periodically so NFR-1 holds.
- (assumption) Chromium values() does not follow symlinks into cycles; mitigated by isSameEntry guard regardless.
- (event) spine finalized
